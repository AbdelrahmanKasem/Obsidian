## 2. Lecture content

According to the RPD, the lecture topics are:

|No.|Hours|Topic|
|---|---|---|
|1|2|Basic concepts of programming: program, data, algorithm. Simple data types: numeric and character. Type modifiers. Variables and constants. Type conversion.|
|2|2|Operations and operators. Structural operators of the C language.|
|3|2|Data placement in memory, memory classes. Concept of a statement block. Lifetime and scope of a variable. Local and global variables.|
|4|2|Numeric arrays and strings.|
|5|2|User functions (basic concepts). Declaration, definition, parameters (formal and actual), return value, function call.|
|6|2|Pointers (basic concepts). Pointer arithmetic (address arithmetic). Pointers and arrays.|
|7|2|Dynamic memory management.|
|8|2|Practice of using pointers with dynamic memory and user functions.|
|9|2|User data types: structures, enumerations.|
|10|2|User data types: bit fields, unions.|
|11|2|Stream input/output. Text and binary streams. Console input/output.|
|12|2|Stream input/output. File input/output.|
|13|2|Pointers continued. Practice with dynamic multidimensional arrays. Function pointers.|
|14|2|Linear dynamic structures: implementation of a singly linked list and basic list operations.|
|15|2|Data protection in modular programming. Concept of constants. Overview of C libraries.|
|16|2|Preprocessor and macro tools.|

> Note: the RPD table for Module 2 is slightly inconsistently formatted in the PDF, but these are the lecture-type topics listed there.
