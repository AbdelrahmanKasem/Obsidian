## 2. Lecture content

According to the RPD, the lecture topics are:

| No. | Topic                                                                                                                                                        |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1   | Basic concepts of programming: program, data, algorithm. Simple data types: numeric and character. Type modifiers. Variables and constants. Type conversion. |
| 2   | Operations and operators. Structural operators of the C language.                                                                                            |
| 3   | Data placement in memory, memory classes. Concept of a statement block. Lifetime and scope of a variable. Local and global variables.                        |
| 4   | Numeric arrays and strings.                                                                                                                                  |
| 5   | User functions (basic concepts). Declaration, definition, parameters (formal and actual), return value, function call.                                       |
| 6   | Pointers (basic concepts). Pointer arithmetic (address arithmetic). Pointers and arrays.                                                                     |
| 7   | Dynamic memory management.                                                                                                                                   |
| 8   | Practice of using pointers with dynamic memory and user functions.                                                                                           |
| 9   | User data types: structures, enumerations.                                                                                                                   |
| 10  | User data types: bit fields, unions.                                                                                                                         |
| 11  | Stream input/output. Text and binary streams. Console input/output.                                                                                          |
| 12  | Stream input/output. File input/output.                                                                                                                      |
| 13  | Pointers continued. Practice with dynamic multidimensional arrays. Function pointers.                                                                        |
| 14  | Linear dynamic structures: implementation of a singly linked list and basic list operations.                                                                 |
| 15  | Data protection in modular programming. Concept of constants. Overview of C libraries.                                                                       |
| 16  | Preprocessor and macro tools.                                                                                                                                |

> Note: the RPD table for Module 2 is slightly inconsistently formatted in the PDF, but these are the lecture-type topics listed there.
