## 6. Laboratory report procedure

From the file «Порядок выполнения лабораторных работ»:

1. Exercises are done in parallel with studying the theoretical material.
    
2. After each exercise, results are entered into the report.
    
3. If an error appears, first try to determine its cause and correct the command yourself; if repeated attempts fail, consult the teacher.
    
4. Finish at home any exercises not completed during the class.
    
5. After the exercises, complete additional independent-work tasks.
    
6. Prepare a report as an **interactive Python script (`.ipynb`)**.
    
7. The report must include:
    
    - laboratory work number,
        
    - full name,
        
    - group, using markup code.
        
8. For each completed exercise, include:
    
    - exercise number,
        
    - exercise text,
        
    - commands copied from the command window with comments,
        
    - results of their execution,
        
    - conclusions.
